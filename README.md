# AI Bug Investigator 🐞🤖

An AI-powered debugging assistant that helps developers analyze errors, understand root causes, and get intelligent debugging suggestions using Generative AI.

The goal of this project is to reduce debugging time by transforming raw error messages into structured, actionable insights.

---

## 🚀 Project Overview

Debugging is one of the most time-consuming tasks for developers. Understanding error messages, finding root causes, and searching for solutions can take hours.

AI Bug Investigator acts as an intelligent debugging companion that helps developers:

- Analyze error messages
- Identify possible causes
- Explain technical issues clearly
- Suggest debugging approaches
- Provide AI-powered solutions

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/sabrinshabbirs07-boop/Ai-Bug-Investigator.git
```

Go to project folder:

```bash
cd Ai-Bug-Investigator
```

---

# Backend Setup

Navigate to server:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Create `.env` file:

```
PORT=5000
GROQ_API_KEY=your_api_key_here
```

Start server:

```bash
npm start
```

Backend runs on:

```
http://localhost:5000
```

Health check:

```
GET /api/health
```

Response:

```json
{
  "status": "ok"
}
```
